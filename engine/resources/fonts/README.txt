mx12.mxf: the engine's UTF-8 pixel font (ASCII, all of GB2312, symbols, block and box
drawing), used by engine/render/font.c and the MEXNya Editor.

It is baked by engine/tools/gen_font.py from Fusion Pixel Font 12px (proportional,
zh_hans) by TakWolf, which is distributed under the SIL Open Font License 1.1 (OFL.txt
here). The file is a derivative of that font and is under the OFL; it uses the generic
name mx12 and no reserved font name. The fonts Fusion Pixel builds on (Ark Pixel,
Cubic 11, Galmuri) are OFL as well; their notices are in
assets_src/fonts/fusion-pixel/LICENSES/.
